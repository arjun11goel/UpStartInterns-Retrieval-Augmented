# Task 11: NumPy Student Marks

## 📌 Project Overview
This project demonstrates the fundamentals of numerical analysis using Python's NumPy library. By creating a dataset of student marks, this notebook calculates and explains key statistical metrics to understand the distribution and performance of the class.

## 🎯 Objective
Learn how NumPy can efficiently perform numerical analysis on datasets.

## 🛠️ Tools & Technologies
* **Language:** Python 3.x
* **Library:** NumPy
* **Environment:** Jupyter Notebook

## 📋 Features
1. **Data Creation:** Manually creates a NumPy array representing student marks out of 100.
2. **Statistical Analysis:** Utilizes built-in NumPy functions to compute:
   * `np.mean()` - Average score
   * `np.median()` - Middle score
   * `np.max()` - Highest score
   * `np.min()` - Lowest score
   * `np.std()` - Standard deviation
3. **Data Interpretation:** Provides a plain-English explanation of what the calculated statistics mean in the context of student performance.
4. **Interview Prep:** Includes common interview questions and answers related to NumPy and standard deviation.

## 🚀 How to Run
1. Ensure you have Python installed on your system.
2. Install Jupyter Notebook and NumPy if you haven't already:
   ```bash
   pip install notebook numpy
   ```
3. Clone or download this repository.
4. Open your terminal or command prompt, navigate to the project folder, and launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
5. Open the `.ipynb` file and run the cells sequentially (Shift + Enter).

## 💡 Key Takeaways
* **NumPy Efficiency:** Core operations in NumPy are written in C, allowing for fast, vectorized mathematical operations without needing standard Python loops.
* **Standard Deviation:** A crucial metric in machine learning and statistics that helps determine how spread out the data points are from the average.
